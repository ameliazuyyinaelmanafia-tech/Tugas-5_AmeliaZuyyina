# Acceptance Criteria

## US-01
- Bulan dapat dipilih.
- Tahun dapat dipilih.

## US-02
- Dataset sesuai periode dimuat.
- Data dapat digunakan untuk proses berikutnya.

## US-03
- X1 dan X2 dapat dibentuk.
- Nilai tidak wajar ditangani.
- Normalisasi Min-Max menghasilkan nilai pada skala yang sesuai.

## US-04
- K-Means menggunakan k=3.
- Centroid awal dapat ditentukan.
- Jarak Euclidean dihitung.
- Centroid diperbarui.
- Proses berhenti ketika konvergen.

## US-05
- Nilai Silhouette Score dapat dihitung.
- Nilai rata-rata dapat ditampilkan.

## US-06
- C1 ditampilkan sebagai kedisiplinan tinggi.
- C2 ditampilkan sebagai kedisiplinan sedang.
- C3 ditampilkan sebagai kedisiplinan rendah.

## US-07
- Tombol proses bertahap menampilkan proses K-Means hingga selesai.
- Tombol hasil otomatis menjalankan proses hingga konvergen.
