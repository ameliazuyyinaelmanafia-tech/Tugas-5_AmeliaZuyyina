# User Stories

## US-01 Pilih Periode
Sebagai admin, saya ingin memilih periode bulan dan tahun agar sistem memuat data presensi yang sesuai.

## US-02 Muat Data Presensi
Sebagai admin, saya ingin sistem memuat data presensi berdasarkan periode agar data siap dianalisis.

## US-03 Proses KDD
Sebagai admin, saya ingin sistem melakukan selection, preprocessing, dan transformation agar data siap untuk clustering.

## US-04 Jalankan K-Means
Sebagai admin, saya ingin menjalankan K-Means agar pegawai dapat dikelompokkan berdasarkan tingkat kedisiplinan.

## US-05 Evaluasi
Sebagai admin, saya ingin melihat Silhouette Score agar kualitas klaster dapat dievaluasi.

## US-06 Lihat Hasil
Sebagai admin, saya ingin melihat kategori kedisiplinan setiap pegawai agar proses monitoring lebih mudah.

## US-07 Proses Otomatis
Sebagai admin, saya ingin menjalankan proses otomatis sampai konvergen agar tidak perlu menghitung iterasi secara manual.
