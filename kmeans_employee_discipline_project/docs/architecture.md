# Architecture Notes

## Teknologi yang disarankan
- Frontend: HTML/CSS/JavaScript atau framework web.
- Backend: Python dengan FastAPI/Flask.
- Data processing: Python dan pandas.
- Machine Learning: scikit-learn atau implementasi K-Means sendiri untuk kebutuhan pembelajaran.
- Database: MySQL atau PostgreSQL.
- Format pertukaran data: JSON.

## Prinsip
K-Means Clustering menjadi metode utama. KDD digunakan sebagai alur pengolahan data, sedangkan aplikasi web dan database mendukung penyajian serta pengelolaan hasil.
